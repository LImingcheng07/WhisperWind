# 三角洲自动口琴 · 整合设计稿 v1

> 目标：整合市面上所有自动口琴项目的优点，加原创想法，做一个**精美 + 智能**的版本。

---

## 1. 市面现状 & 用户痛点（整合分析）

### 1.1 已有项目盘点

| 项目 | 作者/平台 | 技术栈 | 优点 | 缺点/痛点 |
|---|---|---|---|---|
| **HarmonicaAutoplay** | Cuirx（博客+网盘） | .NET 10 + WPF + DryWetMIDI, SendInput | 安全性（仅 SendInput）、22 个单元测试、原子写配置、播放前冲突校验、UI 三页+主题 token、HDR 高 DPI、进程级兜底松键 | **不开源**、仅 Windows、纯 MIDI 输入、UI 偏工具感、谱子全靠自己找/适配 |
| **HarmonicaPlayer** | B 站 UP + Quark 网盘 | 未公开 | 提供 4 首现成 MIDI（鸟之诗/春日影/父亲/远航星） | 闭源、配置 JSON 要 fork 分支写 |
| **GO_Midi** | qr-rp（GitHub, 15⭐） | C++17 + wxWidgets + CMake | **多通道可分别发到不同窗口**、智能移调、内置 FF14/燕云映射 | 无三角洲映射、C++ 门槛高、需 CMake 二次开发 |
| **MidiAutoPlayer** | frg666（GitHub） | WPF + WPF-UI (Fluent) + DryWetMidi | 自动升降调独立存储、小键盘快捷键 7/8/9、Fluent 设计感 | 原神向、无窗口检测、无安全确认 |
| **of-lyre** | byzp（GitHub, 10⭐） | Python | **在线曲库**、合奏多机、CLI 无 UI 模式、工具脚本齐全 | 21 键乐器、需要联网、CLI 门槛高 |
| **nishuihanmAutoPlay** | Ayusid（GitHub） | C# | 简单、C Major 白键限制 | 逆水寒向、白键限制严 |

### 1.2 共性痛点（用户真实抱怨）

1. **谱子难找**：现成适配的 MIDI 极少，大量靠社区手动 fork JSON 分支。
2. **音域受 8 键限制**：原曲移调/超出音域时只能"折八度+丢音"，听感偏离严重。
3. **无人声/无伴奏**：干吹旋律，沉浸感差。**竞品全部是单音轨**。
4. **UI 工具感强**：所有 WPF/wxWidgets 项目都是"工程师审美"，没有设计感。
5. **闭源/难二次开发**：Cuirx 这套最稳但不开源；其他要么 fork 要么从零造轮子。
6. **安全机制不统一**：有些无确认、无窗口检测、无兜底松键。
7. **不支持手机/模拟器/跨平台**：用户可能用 MuMu 玩手游三角洲。
8. **学习曲线**：每个项目都要"先开游戏→再开程序→F8→3 秒倒计时"，新用户不友好。

### 1.3 三角洲游戏的特殊约束（关键事实）

- 口风琴**只有 8 个音**（C/D/E/F/G/A/B + 半音）
- **鼠标中键** = 升半音（黑键）
- **鼠标右键/侧键** = 换八度
- **一次只发一个音**（单音乐器，不是和弦）
- S11 限定口琴任务需按 7 位数字码提交（NPC：佐拉 7676354、老乔 5123543123、唐吉 6712171）
- 模拟输入可能违反用户协议（ACE 反作弊），但纯 SendInput 风险相对低

### 3.3 核心数据流

```
MIDI 文件
   ↓
MidiSong 解析（轨道+绝对毫秒+速度变化）
   ↓
TrackSelector AI 选轨（默认用启发式，可切 AI）
   ↓
SmartTranspose 智能移调（最小丢音）
   ↓
HarmonicaMapping 映射到按键组合
   ↓
PlaybackPlan 校验冲突/密度/可播性
   ↓
Player 状态机（IDLE → COUNTDOWN → PLAYING → PAUSED → STOPPED）
   ↓
WindowsInput.SendInput
   ↓
NativeInputSafety 进程级兜底（任何路径都松键）
```

## 6. 智能特性详解

### 6.1 AI 智能选轨

输入：MIDI 文件（多轨）
启发式（默认无 API）：
- 每轨平均音高 → 取中音区
- 音符密度 → 取不密不疏
- 时长分布 → 取长句多于短句
AI 增强（启用后）：
- 调 Claude/GPT，prompt 给出每轨特征，问"哪条最像主旋律"
- 缓存结果，下次同 ID 复用

### 6.2 智能移调

```
输入：原始音域 [low, high]
目标音域：游戏 8 键的可达范围
算法：
  1. 列出 12 个半音移调方案
  2. 对每个方案计算：丢音率（音域外）+ 冲突率（同音名重）+ 风格损失
  3. 加权得分，取最佳
  4. 若仍 > 5% 丢音，建议切 1.5x 速度 + 跨八度对换
```

### 6.3 曲谱可演奏性评分

```
score = 100
       - 30 * 丢音率
       - 20 * 同名冲突率
       - 15 * 极快音符占比
       - 10 * 长延音占比
       + 5  * 适中性（80-120 BPM 加分）
       + 社区上传者信誉分
```

### 6.4 语音控制（本地 Whisper tiny）

- 唤醒词："小风"
- 命令集：播放/暂停/停止/下一首/速度 X
- 失败回退到 Windows.System.Speech（更快但准确度低）

## 7. 与 ACE 反作弊的风险说明

- **本工具仅用 `SendInput`**（user32 公开 API）—— 与键盘宏、AutoHotkey 同级别
- **不读内存、不注入、不驱动、不改文件**
- **风险等级**：与所有同类工具相当（HarmonicaAutoplay/GO_Midi 同档）
- **缓解措施**：
  - 默认关闭游戏输出（必须显式勾选 + 二次确认）
  - 程序认窗口（前台非游戏自动暂停）
  - 任何路径都兜底松键
  - 启动提示 + 每次输出前确认
- **不规避 ACE**，不做内核 hook / 内核驱动（无意义也违规）
- **不做 PvP 战斗辅助**（仅口琴这一非战斗场景）
